    ACADE Introduction

    Automatic CAe driven DEsign
    Free Online Flow Mesh Generation & CFD Calculation Toolkit
    Integrated tools of automatic structured mesh generation for turbomachinery flow fields / mesh adaptation with boundary layer for aircraft external flow fields

    ACADE-Turbo

    Structured Mesh Generation

    Automatically generates high-quality structured flow passage meshes from blade profile curves. Supports single-layer extrusion or multi-layer blade input, capable of handling complex geometric features such as tip clearance.

    Applications: Airfoil analysis, turbine/compressor cascades, single-stage turbine test rigs

    ACADE Powered by SU2 | Gmsh

    Adaptive Mesh Simulation

    External flow solver based on unstructured meshes with adaptive mesh refinement technology, enabling high-fidelity Euler and RANS simulations.

    Applications: Airfoils, wings, full aircraft configurations, delta wings, and other external flow analyses

    SU2 Powered by SU2

    General Flow Computation

    A customized flow solver based on the open-source SU2 framework, capable of performing Euler and RANS simulations on meshes generated by ACADE-Turbo and ACADE.

    Applications: General-purpose internal and external flow computations
